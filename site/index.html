● Features

Everything you need to code from a phone

Vibecoder ships with the tools a real coding session needs — file ops, search, shell, web fetch, notifications, and tailnet check — all controlled by the agent.

📁

File tools

Read, write, edit, and list directories. The agent explores your codebase, creates files, and makes surgical edits without clobbering what's already there.

🔍

Search & grep

Glob files by pattern and search contents with regex. Find the right file and the right line before touching anything.

🖥️

Bash

Run shell commands — git, builds, installs, scripts, tests. The agent batches work into one command where it can, and never runs destructive commands silently.

🌐

Fetch URLs

Read documentation, API responses, and web pages as part of the agent's reasoning. Capped output so big pages never blow context.

🔔

Termux notifications

The agent fires a notification to your Android status bar when a long task finishes. Step away from the phone — you'll know when it's done.

🔗

Tailscale status

Before reaching a server on another device (e.g. your Oppo home server), the agent checks the tailnet tunnel. If it's down, it tells you rather than guessing at an unreachable IP.

🧠

Dual-model routing

A fast model handles chat and simple queries; a heavy reasoning model takes coding and complex tasks. You use the cheap model all day and only burn the big model when it matters.

⚡

Offline queue

Heavy tasks get queued automatically when your connection drops, and run the moment connectivity returns. Work keeps moving on spotty mobile data.

● How it works

Three steps from install to coding

No PC, no account dance, no opaque framework. Install, set a key, and start talking to your agent.

1. Install on Termux

One-time Bun install, then clone vibecoder and link it. The vibecoder command is on your PATH — callable from anywhere in Termux.

2. Set a free API key

Grab a free GROQ key (qwen3.8-27b, gpt-oss-120b) or a free NVIDIA NIM trial (Nemotron 3 Ultra 550B). Drop it in a gitignored .env. No card required for the free tiers.

3. Talk to your agent

Open vibecoder and describe what you want. The agent explores, decides, acts, observes, and iterates — reading files, running commands, writing code — until the job is done.

Optional: install Ollama in Termux and pull a small local model (qwen2.5:1.5b) for offline chat. Vibecoder auto-detects it. Most people use the free online providers and skip local models entirely — your phone never has to run a big model.

● Use cases

What people actually do with it

Vibecoder is a general coding agent — but on a phone, the use cases that matter are the ones you can do anywhere, anytime.

On the go

Quick coding sessions

Write a script, fix a bug, build a small tool — between things, on the train, on the couch. No laptop required. The agent does the threading; you describe the outcome.

Automation

Phone-side automations

Have the agent run repetitive tasks on your device — organize files, batch-rename, fetch and process data, run a build and notify you when it's done. Set it going and walk away.

Offline-resilient

Spotty data? No problem

Heavy tasks queue automatically when connectivity drops and run when it returns. You can keep talking to the agent on the local model (if you have one) or just queue up work for later.

Multi-device

Reach your other devices

With Tailscale up, the agent can check the tunnel and reach a server on another device — your Oppo home server, a VPS, a NAS. One agent, several machines, all from your phone.

Learning

Explore and understand code

Drop into any codebase, ask the agent to explain it, trace how pieces fit together, and grep for the thing you actually care about. Read-only investigation before you touch anything.

Building

Build real things

The heavy model (Nemotron 550B) takes on real coding tasks — multi-file work, debugging, refactoring. The agent keeps context across steps and tool calls until the job is done.
